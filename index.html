How large AI models are trained, served and run, computed from each model's published configuration. Numbers are parameter counts, bytes and FLOPs, so they apply to any hardware; GPU memory and GPU count at the top are the only hardware inputs.

The order of topics follows Andrej Karpathy's video Deep Dive into LLMs like ChatGPT (2025), extended with model architectures, ways to run models and other model families. Text and figures on this page are original.
